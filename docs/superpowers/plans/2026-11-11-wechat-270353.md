# WeChat 270353 Implementation Plan

> Execute in this chat; do not commit or push. The supplied source is an archive without `.git`.

**Goal:** On macOS arm64 build 270353, retain messages recalled by others, put a persistent `对方尝试撤回此消息` label beside the original, and keep the user's own recalls native.

**Architecture:** Pin the actual Mach-O UUID and instructions. A native runtime handles the incoming replacement path and attaches a Qt QLabel through the client's own Qt instance and message layouts. Persist only account, session and message ID; retain the original message in WeChat's own storage.

**Tech Stack:** Existing Swift 6 / ArgumentParser, system Foundation and C++17; no second Qt runtime or hook dependency.
